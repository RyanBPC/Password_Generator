# Password Generator (Python)

This is a straightforward Python password generator I built to practice working on with loops, lists, and randomisation. It asks the user how many letters, symbols, and numbers they desire, then builds a password using those choices and shuffles everything to make it unguessable. It's quite a small, but practical tool that supported me getting comfortable with combining user input and random logic.

---

## What It Does

- Lets the user choose how many letters, numbers, and symbols you want
- Randomly selects characters from every pool
- Shuffles everything to avoid any predictable patterns
- Builds a display and final password

---

## Project Structure

```
Password_Generator/
│
└─ Password_Generator.py            # Main password generator logic
```

---

## How To Run It

Run the script in your terminal:

```
Password_Generator.py
```

You'll be asked how many letters, symbols, and numbers you want, and the program will decide to generate you a custom password based on your inputs.
